## 2. 실측 대조 (Spearman 순위 상관)

격자 점수를 **구·군으로 집계**해 경찰서별 절도 건수와 대조했다.
부산 16개 경찰서는 16개 구·군과 **이름으로 1:1 대응**한다(수영서가 별도로 있어 남부서=남구만 담당).

| 비교 | Spearman | 해석 |
|---|---|---|
| 취약도 합계 vs 절도 총량 | **+0.159** | 규모 대 규모 |
| 평균 취약도 vs 절도 총량 | **+0.421** | |
| **평균 취약도 vs 절도 발생률**(10만 명당) | **−0.079** | **음의 상관** |
| R등급 격자 수 vs 절도 총량 | +0.319 | |
| (기준선) 격자 수 vs 절도 총량 | +0.156 | 면적만으로 이만큼 |
| **(기준선) 인구 vs 절도 총량** | **+0.794** | **인구가 압도적** |

**n=16** (구·군 전수). 격자 12,538개 — 미매칭 901개 제외, 근거는 2-1.

### 2-1. n=15 → n=16 수정 (2026-08-25)

기장군만 코드가 `21510`으로 건너뛰어(나머지는 `21010`~`21150`) 대조에서 조용히 빠져 있었다.
`verify_correlation.sql`은 구·군 16행을 **손으로 박아** 범위 추측을 없앴다.

| 비교 | n=15 | **n=16** |
|---|---|---|
| 합계 vs 총량 | +0.282 | **+0.159** |
| 평균 vs 총량 | +0.386 | **+0.421** |
| 평균 vs 발생률 | −0.179 | **−0.079** |
| 인구 vs 총량 | +0.818 | **+0.794** |

**합계 계열이 절반으로 떨어졌다.** 기장군은 격자 3,513개(전체의 26%)로 최다인데 절도는 595건뿐이라
"격자가 많으면 절도도 많다"는 관계를 정면으로 깬다. **결론은 바뀌지 않는다** —
발생률과는 여전히 음의 상관이고, 인구 하나가 우리 지표 전부보다 강하다.

### 2-2. 미매칭 격자 901개(6.7%)는 제외

centroid가 행정동 폴리곤 밖(해안 경계·매립지)이라 구·군에 귀속되지 않는다.

| | 강서 | 기장 | 사하 | 나머지 |
|---|---|---|---|---|
| 미매칭 | 347 | 169 | 130 | 255 |

평균 점수가 매칭분보다 일관되게 낮다(강서 0.124 vs 0.151, 금정 0.109 vs 0.156).
인구가 안 붙어 **표적지수가 하한 0.15에 고정된 탓**이므로, 이 낮은 점수는 "안전"이 아니라 **"데이터 없음"** 이다.
최근접 구에 붙이면 면적 큰 구의 평균이 데이터 부재 때문에 더 내려가므로 버리는 쪽을 택했다.

### 2-3. "빈 격자 희석" 제거는 실패했다

산·농지·항만의 빈 격자가 면적 큰 구의 평균을 끌어내린다고 보고,
인구가 있는 격자만의 평균(`score_avg_pop`)을 따로 냈다. **원래 평균과 완전히 같은 값이 나왔다.**

```
매칭 격자 12,538개 → pop_est > 0 인 것 12,538개 (최소 2.25)
```

인구를 **면적 비례로 배분**했기 때문에 행정동 안이기만 하면 산이든 농지든 인구가 붙는다.
즉 인구로는 빈 격자를 걸러낼 수 없다. 기장군이 격자 3,513개인데 R등급이 14개뿐인 것도 같은 구조다.
→ `weights.md`가 지적한 면적 비례 배분의 한계가 실제로 어디까지 번지는지 보여주는 사례다.
희석을 제거하려면 건물 연면적 가중 배분이 필요하다(6절).

| 구·군 | 평균 취약도 | 10만 명당 절도 | 격자 | R등급 |
|---|---|---|---|---|
| 중구(원도심) | 0.170 (하위) | **1,623.8 (1위)** | 48 | 5 |
| 부산진구 | 0.213 | 735.3 | 478 | 117 |
| 동래구 | 0.274 (2위) | 482.5 | 267 | 149 |
| **수영구** | **0.289 (1위)** | **181.2 (최하위)** | 169 | 93 |
| 강서구 | 0.151 | 241.5 | 2,967 | **269 (최다)** |
| 기장군 | 0.121 (최하위) | 343.5 | **3,513 (최다)** | 14 |

- **수영구**: 지수 1위, 실제 발생률 최하위
- **중구**: 지수 하위권, 실제 발생률 1위
- **강서구**: R등급 격자가 269개로 가장 많은데 발생률은 하위권.
  격자 수가 많아서 생긴 결과다 — R등급은 **부산 전체 상위 10%** 컷이라 면적이 넓으면 R도 많이 나온다.
  "R등급이 많은 구 = 위험한 구"로 읽으면 안 된다는 뜻이다(발표 시 주의).
- **기장군**: 격자는 최다인데 평균 취약도는 최하위. 산·농지 격자가 평균을 끌어내린다(2-3)

## 4. 원인 — 역인과(reverse causality)

**CCTV 부재(가중치 0.30)가 방향을 거꾸로 끌었다.**

원도심(중·서·동구)은 CCTV가 촘촘해 "부재" 점수가 낮게 나오는데, 실제로는 유동인구·상권 때문에 절도가 가장 많다.
반대로 수영구는 CCTV가 상대적으로 적어 지수가 높지만 실제 절도는 적다.

이는 **"CCTV가 절도를 못 막는다"는 뜻이 아니다.** 인과가 반대일 가능성이 크다 —
**절도가 많았던 곳에 CCTV를 설치했다**(대응적 설치). RTM에서 잘 알려진 함정이다.

그리고 절도 총량은 인구가 **+0.794**로 설명한다. 즉 **"사람이 많은 곳에 절도가 많다"** 는 사실이
우리가 만든 어떤 환경 지표보다 강하다.

**단, n=16 재계산으로 음의 상관은 −0.179 → −0.079로 약해졌다.**
역인과가 방향을 끌었다는 진단은 유지되지만 그 크기는 처음 본 것보다 작다.
n=16에서도 양수로 돌아서지 않았으므로 "예측이 안 된다"는 결론은 그대로다.

## 5. 결정 — 지표 재정의 (2026-08-25)

**절도 발생 예측을 포기하고, 측정하고 있는 것을 정확한 이름으로 부른다.**

| | 전 | 후 |
|---|---|---|
| 이름 | 자전거 도난 위험지수 | **자전거 도난 환경 취약도** |
| 의미 | 이 격자에서 도난이 일어날 가능성 | 이 격자의 **감시·조명 인프라가 부족한 정도**(표적이 있는 곳 중에서) |
| 실측 대조 | 검증 기준 | **참고 자료** — 왜 예측이 안 되는지 설명하는 근거 |

### 왜 이게 더 나은가
- **정직하다.** 검증이 실패했는데 "예측"이라고 부르면 그건 허위다.
- **정책적으로 쓸 수 있다.** "어디에 CCTV·보안등을 놓을까"에 바로 답한다. 절도 예측보다 오히려 실행 가능한 정보다.
- **발표에서 강하다.** "예측했다"보다 **"검증해보니 예측은 안 됐고, 역인과 때문이라는 것을 데이터로 확인했다"** 가 설득력이 크다. 역인과를 짚어낸 것 자체가 분석 성과다.

### 채택하지 않은 대안
- **가중치를 실측에 맞춰 재조정**: 검증 데이터로 튜닝하면 검증이 아니게 된다(`plans/crime-prediction.md` 4-3에 금지로 명시).
- **CCTV를 빼고 인구·상권 중심으로 재설계**: 결국 "인구 많은 곳이 위험"에 수렴한다(인구 단독 +0.794). 그건 지도로 만들 가치가 없다.
